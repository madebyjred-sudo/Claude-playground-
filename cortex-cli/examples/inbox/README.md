# Inbox

Tirá acá tus PDFs, Words, EPUBs y .txt. Cuando corras `cortex` y
elijas "crear nuevo córtex" → "usar la carpeta default", esta es la
carpeta que se va a procesar.

Esta carpeta también está disponible dentro de tu Drive (si elegiste
Google Drive / iCloud / Dropbox / OneDrive durante el setup). Eso
significa que podés tirar archivos acá desde tu celular, tu otra
computadora, o desde la web del servicio que uses.

## Tipos de archivo soportados

- `.pdf` — PDFs en general (libros, papers, reportes)
- `.docx` — Word
- `.epub` — libros en formato EPUB
- `.md` / `.markdown` — Markdown
- `.txt` — texto plano

## Lo que NO va en el inbox

- Imágenes, audio, video — no los parseamos todavía.
- Archivos personales o sensibles que no querés indexar.
- READMEs (este archivo se ignora).
