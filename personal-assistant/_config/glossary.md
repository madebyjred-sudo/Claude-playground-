# Glosario

> Vocabulario propio de Jred — proyectos, lugares, abreviaturas, jerga interna. El agente lo carga para resolver términos que de otra forma serían ambiguos.

Formato:

```
**término**: definición breve. Opcional: link a nota relacionada.
```

---

<!-- Llenar conforme aparezcan términos -->

**ICM**: Interpretable Context Methodology. Ver `vendor/icm-template/docs/methodology.md`.

**workspace**: en jerga ICM, una carpeta autocontenida con IDENTITY + CONTEXT + stages. Este `personal-assistant/` es un workspace.

**stage**: un paso del pipeline. Tiene su propio `CONTEXT.md` (contrato) y `output/`.
